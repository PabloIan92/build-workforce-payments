# Seguridad, privacidad y cumplimiento

- Autentica con un proveedor confiable y aplica mínimo privilegio.
- Separa captura, aprobación, ejecución y conciliación.
- Protege datos bancarios, fiscales, salariales y biométricos.
- Evita guardar documentos o fotos como contenido público.
- No registres datos personales, coordenadas ni importes sensibles en logs.
- Usa cifrado, enlaces de corta duración y rotación de secretos.
- Define retención por categoría.
- Documenta consentimiento para ubicación o fotografías.
- Somete reglas locales a revisión profesional.
- Trata alertas antifraude como señales para revisión humana.

Antes de publicar, busca correos, teléfonos, URLs privadas, tokens, claves, identificadores largos, nombres propios, marcas, cuentas, archivos multimedia y datos productivos. Sustituye todo ejemplo por datos sintéticos.
